# Task Manager Android Application

A comprehensive mobile application developed as part of the Software for Mobile Devices course. This multi-tab application helps users manage their tasks, view past activities, receive notifications, and personalize their experience.

## Features

### 1. Schedule Tab
- Add new tasks with title, description, and datetime
- View upcoming tasks sorted by date
- Mark tasks as complete/incomplete
- Delete tasks

### 2. Past Tab
- View completed and past tasks
- Chronological sorting of past activities
- Task status tracking

### 3. Notification Tab
- View system notifications
- Automatic notifications for task reminders
- Chronological display of notifications

### 4. Profile Tab
- User information management (name, email)
- Theme customization (Dark/Light mode)
- Persistent settings using SharedPreferences

## Technical Implementation

### Database Structure
- SQLite implementation for task and notification storage
- Efficient CRUD operations
- Date-based filtering and sorting

### Data Persistence
- SQLite for task and notification data
- SharedPreferences for user settings and theme preferences

### UI/UX
- Material Design principles
- ViewPager with TabLayout
- Responsive and user-friendly interface
